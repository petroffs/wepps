# Wepps ClientAPP REST API (v1)

- **Базовый URL:** `https://platform.wepps`
- **Сгенерировано:** 2026-10-17 23:58
- **Обёртка ответа:** `{"status": 200, "message": "OK", "data": ...}`
- **HTML-версия (Swagger UI):** [`clientapp.html`](./clientapp.html)

Клиентское API v1 (ClientAPP) — эндпоинты витрины и мобильного приложения:
авторизация, профиль, товары, корзина, заказы, новости, слайды.

- **Авторизация:** Bearer-токен из `POST /rest/v1/auth.login` — подробности в [auth.md](./auth.md).
- **Обёртка запроса:** тело запроса передаётся как `{"data": {...}}`;
  GET-параметры — в query-строке.
- **Обёртка ответа:** `{"status": 200, "message": "...", "data": ...}`.

## Примеры ответов

**Успех:**

```json
{
    "status": 200,
    "message": "OK",
    "data": []
}
```

**Ошибка:**

```json
{
    "status": 400,
    "message": "Field 'name' is required",
    "data": null
}
```

## profile

### `GET /rest/v1/profile`

Профиль текущего пользователя: персональные данные, контакты

### `GET /rest/v1/profile.settings`

Настройки приложения текущего пользователя (тема, уведомления)

- **Авторизация:** `Bearer`

### `PUT /rest/v1/profile`

Обновление ФИО и адреса текущего пользователя. Email и телефон меняются через отдельные эндпоинты с подтверждением

- **Авторизация:** `Bearer`

**Тело запроса** (JSON, ключ `data`):

| Поле | Тип | Обязательный |
|---|---|---|
| `nameSurname` | `string` | нет |
| `nameFirst` | `string` | нет |
| `namePatronymic` | `string` | нет |
| `city` | `string` | нет |
| `address` | `string` | нет |

**Пример запроса:**

```json
{
    "data": {
        "nameSurname": "string",
        "nameFirst": "string",
        "namePatronymic": "string",
        "city": "string",
        "address": "string"
    }
}
```

### `PUT /rest/v1/profile.email`

Смена email (2 шага). Шаг 1: {email} → получение кода подтверждения. Шаг 2: {email, code} → подтверждение смены

- **Авторизация:** `Bearer`

**Тело запроса** (JSON, ключ `data`):

| Поле | Тип | Обязательный |
|---|---|---|
| `email` | `email` | да |
| `code` | `string` | нет |

**Пример запроса:**

```json
{
    "data": {
        "email": "user@example.com"
    }
}
```

### `PUT /rest/v1/profile.phone`

Смена телефона (2 шага). Шаг 1: {phone} → получение кода на email. Шаг 2: {phone, code} → подтверждение смены

- **Авторизация:** `Bearer`
