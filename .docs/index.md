# Документация Wepps Platform

Полная документация по установке, настройке и использованию платформы **Wepps**.

## О платформе

**Wepps** - модульная PHP-платформа для создания веб-сайтов и REST API с использованием MySQL.

### Ключевые возможности

- 🧩 **Модульная архитектура** - расширяемость через систему Extension
- 📊 **Удобная админка** - интуитивное управление контентом
- 🔐 **Система прав доступа** - разграничение доступа пользователей
- 🛒 **E-commerce модули** - каталог, корзина, заказы
- � **REST API из коробки** - автоматический API у любой таблицы данных (M2M и APP-версии)
- �🚀 **Высокая производительность** - кэширование, оптимизация запросов
- 📱 **Responsive дизайн** - адаптивность из коробки

## Быстрый старт

```bash
# 1. Скачайте релиз
# Перейдите на https://wepps.dev/downloads

# 2. Распакуйте архив
cd /var/www/your-project
unzip wepps-release.zip

# 3. Создайте базу данных
mysql -u root -p -e "CREATE DATABASE wepps CHARACTER SET utf8mb4;"

# 4. Настройте конфигурацию
# Отредактируйте config.php с вашими параметрами БД

# 5. Запустите установщик
php install.php
# Установщик запросит у вас логин (email) и пароль администратора

# 6. Готово! Откройте в браузере
# Frontend: https://ваш-сайт.com/
# Admin: https://ваш-сайт.com/_wepps/
```

**Подробнее см. [Установка и настройка](technical/01-installation.md)**

## Системные требования

### Минимальные

- PHP >= 8.1
- MySQL >= 8.0 или MariaDB >= 10.6
- Apache с mod_rewrite
- 256 МБ RAM
- 50 МБ свободного места на диске

### Рекомендуемые

- PHP >= 8.2
- MySQL >= 8.0 или MariaDB >= 10.11
- 512 МБ RAM
- Memcached для кэширования
- SSL сертификат (Let's Encrypt)

### Расширения PHP

**Обязательные:**
- PDO, PDO_MySQL
- mbstring
- curl, xml, zip, dom

**Опциональные:**
- gd или imagick (работа с изображениями)
- memcached (кэширование)

**Установка (Ubuntu/Debian):**
```bash
sudo apt install php8.1-{curl,xml,mysql,mbstring,zip,gd,dom,memcached}
sudo service apache2 restart
```
